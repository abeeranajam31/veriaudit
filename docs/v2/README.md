# VeriAudit v2: documentation index

VeriAudit v2 is a pre-registered study of cross-lingual LLM safety in English, Urdu script, Roman
Urdu and Urdu–English code-switching. Development branch `veriaudit-x-dataset`, draft PR #1.
**No v2 data has been collected yet:** no translation, inference, judging or annotation.
